# P4T4：12页汇报内容规划

2026-11-18。本轮仅规划内容，不创建PPT/PPTX。事实依据为[最终报告](./phase4-final-architecture-report.md)；图预览与制作限制见[渲染记录](./assets/p4t4/README.md)。下列标题和短句可直接作为页面文字，细节留在讲述与备用页。

## 主线逐页规划

### 1 / 一次证据驱动的架构演进

- **唯一观点**：本轮交付是一项可追溯的架构取舍，不是“最优检索算法”宣告。
- 展示：MAGA课程助手；自然需求→课程证据；最终默认Baseline＋原B可选。不要堆全系统功能。
- 图表：问题→候选→实验→ADR→验收五步链。
- 证据：[报告摘要](./phase4-final-architecture-report.md)、[主任务](./phase1-task-definition.md)。
- 讲解：只演进架构实践证据供给，系统保持模块化单体。
- 时间：35秒；追问：为什么值得作为体系结构案例？

### 2 / 召回不足和 Top-8 截断是两个问题

- **唯一观点**：先区分问题机制，才能公平设计候选。
- 展示：N01无关键术语命中；N02定义页排名12；“系统”9分对定义6分。
- 图表：查询→词法排序→8页闸门，标记第12页；不画模型必然答错。
- 证据：[P2原始贡献分解](./phase2-analysis.md)。
- 讲解：相关页可能不存在于召回，也可能已召回但被挤出。
- 时间：50秒；追问：是不是只改同义词就行？

### 3 / 用六个 Drivers 约束设计

- **唯一观点**：覆盖目标同时受性能、可信性、维护和外部依赖约束。
- 展示：D1匹配、D2默认开销、D3可信/连续性、D4局部化、D5可维护测试、D6依赖成本；重点放QAS-02/04。
- 图表：左侧Drivers简表，右侧故障场景卡：规划失败→合法降级；度量200＋明确回退＋真实来源。
- 证据：[P4T2 §2–4六要素](./phase4-architecture-design-and-views.md)。
- 讲解：约束必须保持，覆盖是优化目标；没有补造全业务15秒SLA。
- 时间：55秒；追问：Response Measure如何确定？

### 4 / 三种机制，三个独立候选

- **唯一观点**：竞争实验隔离机制，不能把各方案优势偷偷组合。
- 展示：A词法扩展/排序；B一次规划/多路检索/轮转；C原query Top32/重排/Top8。共同基点c6fc185、真实来源≤8。
- 图表：三列短流程；LLM只在B的规划节点出现。
- 证据：[开发契约](./phase2-implementation-contract.md)、[原型与commit索引](./phase4-evidence-index.md)。
- 讲解：C解决候选选择，不能保证补出零召回知识；Planner不认证页码。
- 时间：55秒；追问：为什么不是统一RAG框架？

### 5 / 统一条件，比来源而非最终回答

- **唯一观点**：指标解释必须携带样本、标注和计时边界。
- 展示：开发12/11评分、保留4/3评分；KC8、P8下界、来源wall；AI标签非人工金标准。
- 图表：数据分层与“需求→已校验来源”计时框，框外最终生成。
- 证据：[正式协议](./phase3-evaluation-protocol.md)、[结果口径](./phase3-evaluation-results.md)。
- 讲解：未审来源不是无关；确定性方案两遍、B一次真实规划；不报生产P95。
- 时间：50秒；追问：小保留集能支持多强结论？

### 6 / B 的局部覆盖收益伴随等待代价

- **唯一观点**：覆盖均值提升不足以证明全面替换。
- 展示：开发KC Baseline/A/B/C=50/31.82/63.64/50%；对应wall=4.259/2.412/11.207/8.444秒；保留B对Baseline1升1降1平。
- 图表：上下对齐双面板柱状图（覆盖%、时间秒，分别坐标）；保留只放升降卡，完整P8留附录。
- 证据：[统一结果](./phase3-evaluation-results.md)、[机器comparison](../../data/verification/p3t3-analysis-20261116-v1/comparison.json)。
- 讲解：同批B开发+13.64个百分点、+6.948秒；不把保留均值当普遍优势。
- 时间：65秒；追问：有没有退化查询？

### 7 / 两次补充优化没有换来稳定净收益

- **唯一观点**：更好的代理目标或Prompt措辞，不等于更好的真实知识覆盖。
- 展示：新测试KC Baseline/B/B-v2=66.67/66.67/55.56%；Coverage同池42评分例0升2降40平；D03丢5:27检查点。
- 图表：两张小结果卡＋D03原B保留/新选择丢失的来源对照。
- 证据：[B-v2](./phase3-b-v2-experiment.md)、[Coverage](./phase3-b-coverage-experiment.md)。
- 讲解：新集AI构建且后续已观察；N13标签漏页，优先用D03解释；不同批延迟不横比。
- 时间：65秒；追问：意图覆盖为什么会失配？

### 8 / ATAM：把结果转为质量属性取舍

- **唯一观点**：同一设计选择可同时改善能力、增加风险与成本。
- 展示：TP1规划→覆盖/延迟；TP2严格校验→可信边界/降级；TP4双路径→局部化/维护。S2/S3/S5标注不同证据强度。
- 图表：机制→两种属性响应→决策后果三列矩阵；风险主题收在页脚。
- 证据：[回顾性ATAM §6–8](./phase4-atam-and-decision-review.md)。
- 讲解：这是回顾性轻量分析，没有正式外部工作坊；敏感参数未扫描不冒称最佳阈值。
- 时间：60秒；追问：Sensitivity与Tradeoff有什么区别？

### 9 / ADR：默认稳定，增强可选

- **唯一观点**：B2是人工批准的有限取舍，不是排行榜第一名。
- 展示：默认Baseline、显式原B；不纳入A/C/变体、不自动路由；接受额外维护/未知费用风险。
- 图表：ADR决策卡，包含Context/Decision/Consequences/Status Accepted。
- 证据：[最终ADR](./phase3-final-architecture-decision.md)。
- 讲解：保留局部能力，不让所有请求承担代价；没有证明用户一定选择正确。
- 时间：50秒；追问：为什么不只留Baseline？

### 10 / 一个后端进程，两条来源路径

- **唯一观点**：架构变化被封装在来源链，原最终生成共享。
- 展示：[C&C预览](./assets/p4t4/02-runtime-context.svg)，旁列统一入口→Baseline/Planner→共同校验→原生成。
- 图表：主线用C&C，Module细图放备用；不得把逻辑角色画成服务。
- 证据：[P4T2视图](./phase4-architecture-design-and-views.md)、[选择性集成](./phase3-dual-strategy-integration.md)。
- 讲解：枚举＋函数分派是Strategy-like；不是完整GoF类族，实验分支没有整体Merge。
- 时间：50秒；追问：模块视图为何不同于部署图？

### 11 / 验收允许降级，但不掩盖失败

- **唯一观点**：业务连续性与增强成功率必须分开。
- 展示：原FAIL→人工裁定→复验PASS；真实2 Enhanced / 1 Degraded / 0 Failure；真实调用仍6次，不新增重跑。
- 图表：三阶段状态卡＋保留旧证据的时间线；演示时插入回退短片段。
- 证据：[验收第11节](./phase3-final-acceptance.md)、[裁定机器结果](../../data/verification/p3t6-adjudication-20261117-v1/adjudication.json)。
- 讲解：原额外断言要求三次Planner均成功；回退符合契约，最终生成失败仍算Failure。
- 时间：65秒；追问：是否为了通过而降低标准？

### 12 / 可追溯的取舍比单次高分更重要

- **唯一观点**：架构演进闭环已形成，证据边界仍需明确。
- 展示：问题→约束→实验反证→ADR→集成验收；局限：AI标签/小样本、费用未知、后台取消、长期教学未测。
- 图表：闭环及“已验证/尚未证明”两列。
- 证据：[最终报告](./phase4-final-architecture-report.md)、[答辩Q&A](./phase4-defense-qa.md)。
- 讲解：Phase3完成不代表所有质量属性充分证明；停止探索，进入材料最终核查。
- 时间：40秒；追问：下一步最小必要工作是什么？

## 时间方案与产品片段

以上合计640秒（10分40秒）。15分钟场次：切页/开场缓冲50秒＋[受控演示](./phase4-demo-script.md)90秒＋答问2分钟，共15分钟。演示只展示标准默认、手动切增强和故障回退，不现场跑完两套三阶段真实生成。

10分钟场次：第3/4/5/8页各压缩15秒，第2/7/10/11页各压缩10秒，第1/12页各压缩5秒，PPT为530秒；以30秒历史回退片段替代现场演示，留40秒缓冲。答问须另安排，不能把15分钟内容硬塞10分钟。

若要求完整现场工作流，另设3–5分钟独立演示，不保证网络等待可压缩；真实业务历史每阶段约30–40秒。默认建议保存证据/受控Mock优先，明确标签，不因赶时间重复发真实请求。
