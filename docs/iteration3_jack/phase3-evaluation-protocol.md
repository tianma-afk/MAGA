## 指标与计时

原scoring.metrics不改。P8下界=已标direct页数/8；KC8=至少一个可用direct替代页命中的知识点数/必要知识点数。按可评分查询宏平均，dev/holdout分开。unjudged不当irrelevant；显式background/irrelevant/unusable分列。失败仍保留、空来源质量计0（可评分）；不删除回退。

完整Recall/nDCG不适用：标注不完整且无可信等级。另记录已判断页direct比例（无判断为null）、未审数量、唯一页比例（空为null）、最大成对文本Jaccard、章节分布、返回页数、C原query Top32知识覆盖上限。文本特征为英文词+中文二元组，辅助指标不表示教学价值。

主计时边界是统一入口query/request→validated selection（包含候选自带出口校验），另计共同独立复核，不将评分/多样性/候选上限诊断计入主wall。各候选诊断分段保持原边界，不能把C特征构造误当纯排序或把B检索合并冒当仅召回。每run先冷加载，不混入暖wall；额外校验包装仅计时不改逻辑。无最终生成计时。报告均值、经验P50；小样本P95不作生产尾延迟承诺，正式3评分保留样本不报P95。

## 批次、重复与预算

1. 协议/工具测试与hash冻结后，N10四方案各一次预检（B真实1次），只检查设施，不按质量改规则。
2. 开发全12条按ID顺序，方案顺序baseline→a→b→c。
3. 保留全4条按ID顺序，方案顺序c→b→a→baseline（抵消部分固定先后影响，不能消除系统负载混杂）。
4. Baseline/A/C每查询暖测2次，比完整sources字典确认确定性；每查询质量取首遍，延迟以两遍中位数后宏平均。B每查询仅1次fresh调用，不重试/不挑结果；不声称稳定性。B全轮1+12+4=17次，最多30，无额外真实失败注入或生成。输出token上限17×1024=17408；输入token事前未知，逐次记录usage，费用未知null。运行器请求前持久化attempt账本，累计预算跨worker限制，失败不重试。

模型复用现有dotenv至B子进程，配置不改不复制不记录key/base。请求模型安全核对并记录，实际返回模型/usage另存；既有15秒规划deadline、temperature0、max_tokens1024、3意图、8000字符上限不变。配置不可用则B标incomplete而非Mock冒充。故障测试禁dotenv/清模型变量并用MockTransport，不计真实调用。

## 分析、审计与有效性

四方案每查询成对，报告六对的P8/KC绝对差值、改善/退化/持平数与极值ID。只3评分保留例，不做显著性或总体优越性结论；不做bootstrap伪精确。开发N01/N02相关而非独立用户。B单次采样可漂移，模型别名非固定权重版本。

结果后只按冻结标签分析；新增页仍unjudged，生成待人工表，不改答案、不调算法。代表案例按各候选最大改善、最差退化、共同不改善、质量相近但成本不同选择；无某类则明示。区分已有标注支持/自动推断/待人工审核；本轮无独立人工确认。候选异常保留原样，评估设施修复须记录新hash且不能混算。

鲁棒性重跑四版本相关API/来源/策略及工具测试；Mock覆盖B超时、非法JSON/意图、网络、取消、回退；真实运行与Mock分表。测试通过不证明真实上游取消计费行为。原始JSONL逐query写入，新目录拒覆盖，失败仅异常类不打印上游原文；记录精确命令/时间与未知量。
