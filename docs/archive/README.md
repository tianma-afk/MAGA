# 历史文档归档

本目录保留文档整理前的历史记录。当前请以以下两个文件为准：

- `docs/FEATURES_AND_INTERFACES.md`：当前功能、API/存储/组件接口、验证与限制。
- `docs/FUTURE_DIRECTIONS.md`：可选功能方向、接口建议和演示思路。

归档内容：

| 文件 | 说明 |
| --- | --- |
| `AGENT_HANDOVER.md` | 早期项目交接、需求演进和历史架构说明 |
| `EXTENSION_POINTS.md` | 整理前的接口与扩展点记录，已合并到当前功能文档 |
| `HANDOVER_TEMPLATE.md` | 早期交接模板 |
| `NEW_FEATURES.md` | 本轮新增功能汇总，已合并到当前功能文档 |
| `plan/` | 早期实施计划与验收记录 |
| `spec/` | 早期产品范围和体系结构说明 |

归档文件中的路径引用可能指向整理前的位置；如与当前代码不一致，以当前代码和两个主文档为准。
