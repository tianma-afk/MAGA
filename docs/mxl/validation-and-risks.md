## 2. 本轮有测试覆盖的关键行为

### 混合检索

- Jina 向量响应结构、输入输出顺序、合法维度、非法值处理。
- 幻灯片级文档索引、已有向量复用、单页内容变化后的增量更新、已删除页面处理。
- 混合排名、英文查询处理、缺索引和异常路径。
- `baseline` / `llm_assisted` / `hybrid` 显式路由，来源真实页码校验。
- 选择 Hybrid 后自动 `ensure`，准备中禁用生成、完成解锁、失败重试、切换策略及取消后的竞态防护。

### 案例驱动实践

- 案例清单不向用户泄露私有 objective Rubric。
- 生成的三个问题必须与预设目标 ID 和顺序一致。
- LLM 英文 Query 校验和来源引用真实性校验；拒绝伪造幻灯片页码。
- 首答、追问、完成的 API 契约；最多三轮回答，最后必须完成当前决策点。
- 三个完成记录是最终评审的必要条件。
- 前端选择案例、回答与追问、生成报告、来源弹窗、保存/恢复与检索策略限制。
- 2026-11-24 回归：**选定案例即可开始**，空需求分析与短分析有效；但独立回答仍需满足回答长度约束。
- 旧版 `/api/design/*`、`#/studio/legacy` 继续有回归测试。

## 3. 不可将自动化通过误写成这些“已验证”

| 项目 | 现状 | 需要的验证 |
| --- | --- | --- |
| 真实 Jina Key 与免费额度 | 未在自动化测试中连接真实账号；测试使用 Mock | 经授权的真实 Key，测试小规模建索引/更新/查询、429 和限额 |
| 真实 LLM 提问、追问、评审质量 | 模型调用契约有测试；生成文本质量没有人工金标准 | 真实模型试运行并由课程教师审查 |
| 混合检索优于旧搜索 | **未证明** | 固定语料 + 标注相关页 + 相同查询，比较 Recall@K/MRR/nDCG |
| 中英跨语言泛化 | 代码路径存在，不代表各种同义表达都可检索 | 中文自然语言/英文术语/中英混合 Query 分层评测 |
| 吞吐、端到端延迟和模型费用 | 尚未正式基准测试 | p50/p95、请求 Token/Jina 用量、索引成本和失败率 |
| 出处的语义支撑 | 引用 ID、真实标题、页码可校验；**不自动检验论断是否被课件支持** | 人工审查 sampled outputs + 教学 Rubric |
| PPT 图片/架构图理解 | OCR 仅提取部分文字；**不理解布局、连线或视觉拓扑** | 如需支持，单独规划视觉模型与引用规则 |
| 多用户、账号、正式考试 | 不属于现有实现 | 鉴权、会话服务端存储、权限、限流、安全测试 |
| 自动监听课件变更 | 没有 watch 服务，只有主动 `ensure` 时重建 | 需求明确后评估文件监听/版本状态推送 |

## 4. 建议补充的验收矩阵

需要外部真实服务且有课件授权时，按以下用例人工检查并记下**具体输入/输出/耗时**：

1. `baseline`：选案例并跳过需求分析，成功生成三个决策点；追问、结题、最终报告可用。
2. `llm_assisted`：同一案例走多条英文 Query，确认课件引用真实，不将模式切换前的结果误判为增强结果。
3. `hybrid`：首次选取时看到 building → ready；确认页数、增量更新量、Jina 请求情况；Query 检索结果与页面一致。
4. `hybrid` 故障：临时使用无效 Jina Key 或断网，明确提示且**不会悄悄回退**到 baseline。
5. 中英混合：分别采用专业英文、中文自然语言、同义改写，按人工标注核对 Top-K，而不仅是观察“有结果”。
6. 生命周期：回答一轮后刷新、退出再进、跳转课件引用返回、取消生成、保存导出、旧草稿 `#/studio/legacy` 打开。
7. 课件修改：改变一页 PPT 或 OCR 后重选 Hybrid，确认 `updated` 与页面原文引用一致，未变页不重复向量化。
8. 安全隐私：确认未提交任何 `.env` 密钥、索引外发内容已获授权、日志与前端响应未泄露凭证。

验收结果建议追加到本文件**独立日期小节**，记录模型、参数、网络、课程版本和实际证据。

## 5. 需要优先关注的风险

**R1. 质量评测缺口（高）**：缺人工 Ground Truth，不能判断 Hybrid 在本课程的优势大小，不能声称提高准确率。

**R2. 外部依赖（高）**：Jina 和 LLM 配置、额度、网络、服务价格可能变化；Hybrid 需要 API Key，构建时会把课程文本发送第三方。

**R3. 检索索引变更时机（中）**：PPT/OCR 内容改变但仍使用现有已 ready 的索引时，可能读取到旧向量；应明确重新 `ensure`。

**R4. 非正式评价（中）**：评语可能缺证据或对合理的不同架构选择产生偏见；不能把阶段性建议写成标准正确答案。

**R5. 分数与模型版本（中）**：融合分数是单次查询内相对值，不是概率或可跨 Query 的通用质量评分；更换模型/课程版本要复核。

**R6. 会话存储（中）**：只存于浏览器；清理站点数据会丢失答复，不具备同步和正式考试审计能力。
