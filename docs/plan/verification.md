## 真实流程

使用实际 book 文件，不用伪造章节：

- 选择章节、手动选页、发送继续学习，回复推进页码。
- 刷新页面恢复消息与学习页码。
- 切换章节后消息隔离，切回原章恢复。
- 点击开始讲解与继续学习，检查来源引用与页码。
- 清空章节前取消确认保留消息，确认后清空当前章。
- Chapter 5 第 17 页请求图解，画布显示心跳检测节点与连线。
- 注入一次 HTTP 502，界面显示失败，重试成功且不重复消息。
- 1440 × 960 桌面、390 × 844 手机尺寸无页面水平溢出。
- 手机端原始课件加载完成，截图检查文字、输入框与资料抽屉。

截图位于 data/verification，属于可再生成的本地产物。
另有模拟接口测试覆盖慢请求时切换章节、取消请求和后续回复隔离。

## 审查修复

- 移除了 React StrictMode 重放时会清空画布的 effect 清理逻辑。
- 真实模型路径强制至少一个合法来源引用，替换模型自拟引用标题。
- 发送模型的历史有条数、单条和总字符边界，本地完整消息不被截断。
- 离线快捷按钮使用后端识别的指令，避免进入无匹配分支。
- 资料面板默认关闭，用户按需展开；小型图使用纵向布局避免标签碰撞。
- 图形组件按需加载，主包与画布分包构建。

## 未验证与限制

未提供模型密钥，因此没有调用真实付费模型。模型网关成功、超时、
非法输出和上游错误场景通过响应替身测试，但不等同于真实模型的
教学质量、延迟、成本或兼容性验收。

仅覆盖有文字支持的心跳监测示例，其余图解依赖真实模型。
