# 学习空间与章节大纲实施计划

## 目标

在基线提交 7410636 之后增加主页、节点式章节思路大纲，移除离线教学。

## 并行职责

- [ ] 大纲 Agent：检查真实七章讲义，建立主题节点与页码映射，完整性测试。
- [ ] 后端 Agent：只允许真实模型教学，缺配置返回结构化错误，提供大纲接口。
- [ ] 前端 Agent：学习空间主页、返回导航、大纲/PPT 联动、配置提醒与测试。
- [ ] 集成人员：环境文件保护、文档更新、真实接口浏览器验收。

## 约束

- `.env` 不提交，`.env.example` 无真实密钥。
- AI 对话禁止回退到离线回答；模型测试采用显式测试替身。
- 大纲描述真实课件主题，不按固定页数伪造主题分组。
- 大纲页码覆盖整章、顺序正确、不越界；课件替换后不使用过期映射。
- 首页不自动跳转章节；学生通过显式选择进入学习。
- 每个手写代码文件不超过 500 行。
