# 章节伴学工作台

## 产品范围

以 book 目录中的一个章节 PPT 为一个可恢复的学习会话。学生持续提问、
按页学习、查看原始课件，并在需要时打开体系结构画布。界面参考 Codex
的简洁工作区，而非课程营销页或复杂仪表盘。

## 已确定的交互

- 左侧章节列表，可以收起；中央为对话与输入框。
- 课件和画布按需打开，避免固定三栏挤占对话空间。
- 每章保存独立的消息和当前页，刷新后恢复。
- 学生可以手动翻页、通过回答中的来源跳页、继续学习和请求自测。
- 原始幻灯片图片优先，转换不可用时明确标注文本预览，不冒充原稿。
- 无密钥时显示课件导读模式，不将规则式回答称为 AI 推理。
- 有密钥时调用真实模型，失败时明确报错，不偷偷退回假回答。

## 实现选择

由实现方选择 React / TypeScript / Vite、FastAPI / Python。
采用模块化单体，不引入多服务部署、向量数据库或多 Agent 运行时。
开发采用并行 Agent；产品本身使用单个有课件上下文的教学模型。
正文以当前章节为边界，跨章节知识扩展不作为第一版承诺。

模型仅生成经过校验的文本、页码引用和节点/边 JSON；不能执行脚本、
任意文件操作或任意前端代码。课件视为知识资料而非系统指令。
API 密钥仅保留服务端环境变量。模型启用后会发送当前问题、部分历史
和相关课件文本给配置的模型服务商。

## 模块边界

- server：课件目录、PPT 解析、教学策略、模型网关、HTTP API、测试。
- web：章节会话状态、对话组件、课件预览、图形画布、样式和单元测试。
- scripts：原始幻灯片渲染和代码行数检查。
- docs：设计、实施记录、架构与验收说明。

每个手写代码文件不得超过 500 行。生成数据和依赖锁文件不作为源码模块。
第一版为单用户本地学习工作台，不包含账号、多用户隔离、云部署、
自动成绩判定或完整物理仿真。

## 验收

真实读取全部已有 PPT；不会捏造缺失章节。可以选择章节、发送问题、
打开课件、查看引用、切换画布、刷新续学。无模型配置也能诚实展示
课件与导读流程。单元测试、前端生产构建和源码行数检查通过，
桌面与移动视口没有水平溢出或不可操作的核心按钮。
